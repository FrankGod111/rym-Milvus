# ERP 知识库控制台 v0.6.0-sandbox 测试输入

## 项目名称
ERP 知识库控制台

## 版本号
v0.6.0-sandbox

## 测试范围
- 登录与 Bearer Token 鉴权
- 普通员工问答入口
- 文档库上传、编辑、权限设置
- 采购审批制度文档同步到 Dify
- Dify 索引状态刷新
- ERP 本地可见文档兜底检索
- 合同对比、纪要生成、测试报告生成三个场景页面
- 历史会话与审批确认页

## 缺陷与现象
- Dify 文档 segment 已生成且索引 completed，但 `/datasets/{dataset_id}/retrieve` 对采购审批问题返回 0 条。
- Dify Chat App Key 当前未配置，AI 问答不能依赖 Dify `/chat-messages`。
- 合同对比、纪要生成、测试报告生成页面目前为 mock 返回，未真正调用 qwen3:8b。
- 合同对比页面当前只上传文件名，未读取文件正文。

## 测试结论
建议作为沙箱演示版本通过，但正式进入业务试点前，需要完成三个场景的 AI 接入、文件正文解析、输出引用来源、错误兜底和审批日志留痕。
